A foundation, not just a lookup

MCPRisky scores the Model Context Protocol server ecosystem — 65,532 servers assessed across seven risk axes (auth strength, capability breadth, data sensitivity, network egress, maintainer trust, exploit surface, overall risk) with trust-gating so established, official publishers aren't false-flagged for being powerful. Here is where it goes.

v1.0 — The scored registry LIVE

  • Authenticated lookup + full per-axis verdict breakdown for every scored server
  • Deterministic trust-gating overrides (official/established maintainers never capped-out on inherent capability alone)
  • Score disputes: challenge an assessment, admins review every one

v1.1 — Perspectives LIVE

  • Admin-built faceted views over the corpus: risk tier × verdict × source × trust band × any of the seven axes
  • Deterministic and reproducible — the same view returns the same servers, no model in the query path
  • Trust-diff: snapshot any perspective and see exactly what entered, left, or changed tier since — the alerting unit webhooks will attach to

v2 (preview) — Ask MCPLookup LIVE

  • Free-text questions over the scored corpus with mandatory citations — every answer names the registry rows it stands on
  • Honest by construction: low-confidence retrieval returns INSUFFICIENT, never a guess
  • Zero-LLM by default; optional phrasing polish never adds facts

Next IN PROGRESS

  • Trust-diff webhooks & notifications on your perspectives
  • Freshness SLA: re-verdict on upstream change, visible last-assessed ages

Ahead RESEARCH

  • Explainable per-axis verdicts (evidence behind every label)
  • Adversarial red-team harness feeding the scoring model
  • Verifiable signed scorecards you can embed and audit
